# Helper

Личный PWA-помощник в одном HTML-файле: питание с распознаванием по фото, вода/шаги/настроение, календарь смен, бюджет и долги, менеджер паролей с TOTP. Всё хранится в браузере в зашифрованном виде, без бэкенда.

## Что внутри

**Питание.** Текстом или фото описываете, что съели — запрос уходит в Gemini (`gemini-2.5-flash` с фолбэком на несколько других моделей серии, если модель недоступна или лимит исчерпан), в ответ прилетают калории и БЖУ. Приложение само делит приёмы пищи на полезные/вредные и считает баланс рациона за день.

**Здоровье.** Вода и шаги — кнопками с быстрым добавлением, вес — отдельная карточка с трендом и спарклайном за последние записи. Настроение фиксируется эмодзи с таймлайном по дню. На вкладке профиля считается суточная норма калорий и воды по формуле Миффлина — Сан-Жеора (пол, возраст, рост, вес, активность, цель — похудение/поддержание/набор).

**Смены.** Шаблон чередования (день/ночь/выходной) применяется на календарь до конца месяца, дальше дни переключаются вручную. По дневной и ночной ставке считается зарплата за месяц.

**Бюджет и долги.** Доходы и расходы по категориям, месячный лимит с индикатором остатка, календарь операций по дням, поиск и фильтры по истории. Отдельно — кто должен вам и кому должны вы, с общим сальдо.

**Пароли и 2FA.** Хранилище шифруется на клиенте (CryptoJS `AES.encrypt` мастер-паролем) и лежит в `localStorage`; без пароля прочитать нечего. Для записей с TOTP-секретом (Base32) коды считаются прямо в браузере через HMAC-SHA1, обновляются каждые 30 секунд. Есть генератор паролей с настраиваемым набором символов и индикатор стойкости.

**Файлы и видео.** Публичный файлообменник кладёт файл (до 15 МБ) в GitHub-репозиторий через Contents API и сокращает ссылку через TinyURL. Загрузчик TikTok берёт видео по ссылке через tikwm.com и даёт сохранить его в галерею без водяного знака.

**Синхронизация.** Зашифрованная база одной кнопкой уходит в приватный GitHub-репозиторий (`encrypted_helper_backup.json`) и оттуда же восстанавливается на другом устройстве — сервер видит только шифротекст. Есть и обычный экспорт/импорт JSON-файлом, плюс выгрузка CSV-отчёта за произвольный период.

## Настройка

В разделе «Настройки» нужно указать:

- **Google AI Studio API key** — для анализа еды по фото/тексту.
- **GitHub Personal Access Token** с правом `repo` — для бэкапов и файлообменника.
- **Репозиторий бэкапов** (приватный, `username/repo`) и **репозиторий файлов** (публичный).

Ключи хранятся вместе с остальными данными внутри зашифрованного хранилища, а не в открытом виде.

## Установка на телефон

iOS (Safari): «Поделиться» → «На экран «Домой»».
Android (Chrome): меню (три точки) → «Установить приложение».

Офлайн работает за счёт `sw.js` — статика кэшируется, HTML обновляется по сети с откатом на кэш при отсутствии соединения.

## Устройство

Один `index.html` (~200 КБ) без сборки и зависимостей, кроме CryptoJS с CDN. Данные лежат в `localStorage` браузера — если очистить хранилище без предварительного бэкапа, всё пропадёт безвозвратно.
