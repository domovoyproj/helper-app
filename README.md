# Helper

Локальный PWA-помощник для задач, здоровья, смен, финансов и личных данных.

[Открыть Helper](https://domovoyproj.github.io/helper-app/) · Версия 2.1.0 · Node.js 22+

## Возможности

- экран «Сегодня» с задачами, балансом месяца, сменой и быстрыми действиями;
- учёт питания, воды, шагов, веса и настроения;
- расчёт КБЖУ по тексту или фотографии через Google Gemini;
- календарь рабочих смен и оценка зарплаты;
- бюджет, категории операций и взаимные долги;
- локальный зашифрованный сейф паролей с генератором TOTP;
- зашифрованные резервные копии в приватном репозитории GitHub;
- сводка из публичного профиля KYD без изменения данных Helper или KYD;
- установка на устройство и работа без сети.

- ускорен запуск тестов в средах без Bun.

## Приватность и данные

Основные данные сохраняются в браузере в зашифрованном контейнере `encMasterData`. Формат контейнера и импорт существующих резервных копий сохранены для обратной совместимости.

Helper обращается к внешним сервисам только для выбранных пользователем функций:

- Google Gemini получает описание или фотографию блюда при запуске анализа;
- GitHub получает зашифрованную резервную копию или загружаемый файл по явной команде;
- KYD читает только публичную сводку по указанной ссылке и не изменяет долги Helper;
- TinyURL и Tikwm используются соответствующими инструментами обмена файлами и видео.

Ключи и токены не должны находиться в исходном коде. Они вводятся в настройках и хранятся внутри зашифрованных данных пользователя.

## Установка

Откройте [веб-приложение](https://domovoyproj.github.io/helper-app/) и выберите «Установить приложение» в настройках Helper или меню браузера. На iOS используйте «Поделиться» → «На экран Домой».

## Локальный запуск

Сборка не требуется:

```bash
python -m http.server 8765 --bind 127.0.0.1
```

После запуска откройте `http://127.0.0.1:8765`.

Проверки:

```bash
npm test
npm run check
```

## Архитектура

- `index.html` — разметка экранов;
- `app.js` — данные, шифрование и основные функции;
- `experience.js` — навигация, сводки, темы и палитра действий;
- `kyd-connector.js` — чтение и нормализация публичной сводки KYD;
- `styles.css` и `experience.css` — базовые и адаптивные стили;
- `sw.js` и `manifest.json` — установка и офлайн-режим;
- `tests/` — модульные тесты без браузерной зависимости.

Архитектурный граф создаётся локально и не коммитится:

```bash
python -m pip install graphifyy
graphify extract . --code-only
graphify query "showSection renderExperience"
graphify affected "updateUI()" --depth 2
graphify god-nodes
graphify explain "connectKYD()"
```

Перед изменением связей кода сверяйте результаты Graphify с исходниками и обновляйте граф после изменений.
