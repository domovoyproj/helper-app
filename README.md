Автономный персональный PWA-помощник нового поколения: умный трекер питания с распознаванием блюд по фото через **Gemini AI**, контроль привычек и здоровья, календарь рабочих смен с расчётом зарплаты, планировщик бюджета, интеграция с финансовой экосистемой **KYD (Kill Your Debt)** и встроенный менеджер паролей с двухфакторной аутентификацией (TOTP).

Работает полностью на стороне клиента: все данные надёжно шифруются мастер-паролем (AES-256) и хранятся в вашем браузере. Выделенный сервер или сторонний бэкенд не требуется.

---

## ⚡ Что нового в Helper 2.0

- 🌟 **Экран «Сегодня»:** сводка активных задач дня, баланс финансов текущего месяца, статус сегодняшней смены и быстрый ввод ключевых показателей.
- ⚡ **Мгновенный трекинг:** быстрые кнопки добавления порции воды (250 мл), шагов, веса и приёма пищи прямо с главного экрана.
- 📱 **Адаптивная эргономика:** боковое меню на десктопе, удобная навигационная панель снизу (Bottom Navigation) на смартфонах, поддержка жестов и плавной анимации.
- 🔒 **Локальная криптография:** CryptoJS 4.1.1 полностью поставляется локально (`vendor/`), устраняя внешние CDN-зависимости.
- 🔗 **Интеграция с KYD:** подключение публичного профиля сервиса Kill Your Debt для отображения сводки долгов и прогресса выплат.
- 💾 **Модернизированный бэкап:** сохранена обратная совместимость со старым форматом шифрования `encMasterData`, экспорт в CSV и JSON.

## ✨ Ключевые возможности

### 🥗 Питание & БЖУ с Gemini AI
- Опишите приём пищи текстом или загрузите фотографию тарелки — нейросеть `gemini-2.5-flash` (с автоматическим фолбэком на альтернативные модели Gemini) распознает блюдо, рассчитает калорийность и распределение белков, жиров и углеводов.
- Автоматическая классификация приёмов пищи на полезные и вредные с расчётом дневного баланса рациона.

### 💧 Здоровье, привычки и профиль
- **Вода и шаги:** быстрый ввод в один клик с отслеживанием прогресса достижения суточной цели.
- **Трекинг веса:** карточка динамики веса со спарклайном последних изменений и расчётом тренда.
- **Трекер настроения:** фиксация эмоционального состояния эмодзи на дневном таймлайне.
- **Индивидуальные нормы:** автоматический расчёт суточной нормы калорий и воды по формуле Миффлина — Сан-Жеора с учётом возраста, веса, роста, физической активности и цели (похудение / поддержание / набор массы).

### 📅 Календарь смен и расчёт зарплаты
- Гибкий генератор циклов чередования смен (день / ночь / отсыпной / выходной) с автозаполнением календаря.
- Ручная корректировка отдельных дней.
- Автоматический расчёт ожидаемой заработной платы за месяц с раздельной дневной и ночной тарифной ставкой.

### 💳 Бюджет, расходы и взаимные долги
- Учёт доходов и расходов с разбивкой по категориям и цветовой индикацией.
- Месячные лимиты бюджета с наглядным прогресс-баром остатка средств.
- Интерактивный финансовый календарь операций и фильтрация истории.
- Раздел взаимных обязательств: кто должен вам и кому должны вы с вычислением общего сальдо.

### 🔐 Менеджер паролей и 2FA (TOTP)
- Защищённый сейф учётных данных, зашифрованный с помощью **AES-256** мастер-паролем.
- Встроенный аутентификатор: генерация одноразовых кодов TOTP (Base32, HMAC-SHA1) прямо в браузере каждые 30 секунд — заменяет Google Authenticator.
- Встроенный генератор сложных паролей с настраиваемой длиной и наборами символов.

### 🔗 Интеграция с KYD (Kill Your Debt)
- Подключение публичного профиля KYD (`https://ваш-kyd.ru/p/имя`).
- Отображение текущего прогресса погашения долговых обязательств, прогнозных сроков и остатка.
- Сводка кэшируется в локальном зашифрованном хранилище Helper и не раскрывает приватные данные.

### 📁 Файлообменник и загрузчик видео
- **Файлообменник:** быстрая загрузка медиафайлов и документов (до 15 МБ) в хранилище [helper-files](https://github.com/domovoyproj/helper-files) через GitHub Contents API с генерацией коротких ссылок TinyURL.
- **TikTok Downloader:** сохранение видеороликов TikTok по ссылке без водяных знаков в память устройства.

### ☁️ Синхронизация и Zero-Knowledge бэкап
- Зашифрованная база данных одной кнопкой отправляется в ваш приватный GitHub-репозиторий (`encrypted_helper_backup.json`).
- Сервер GitHub видит исключительно зашифрованный шифротекст — расшифровать данные невозможно без вашего мастер-пароля.
- Локальный экспорт/импорт всей базы данных в виде единого JSON-файла и выгрузка отчётов за период в CSV.

## 🔒 Безопасность и хранение данных

1. **Zero-Knowledge архитектура:** Ваши пароли, балансы, заметки и медицинские метрики никогда не отправляются на сторонние сервера в незашифрованном виде.
2. **Локальное шифрование:** Ключ шифрования формируется из вашего мастер-пароля. Без него данные в `localStorage` представляют собой бессмысленный набор байтов.
3. **Безопасность API-ключей:** Токены Google AI Studio и GitHub PAT сохраняются внутри зашифрованного контейнера и используются исключительно для прямых клиентских запросов.

## 📲 Установка PWA на смартфон

Приложение работает без необходимости установки из App Store или Google Play:

- **iOS (Safari):**
  1. Откройте приложение в Safari.
  2. Нажмите кнопку **«Поделиться»** (иконка со стрелкой вверх).
  3. Выберите пункт **«На экран «Домой»»** (*Add to Home Screen*).

- **Android (Chrome / Яндекс Браузер):**
  1. Откройте приложение в браузере.
  2. Нажмите на меню (три точки в правом углу).
  3. Нажмите **«Установить приложение»** или **«Добавить на главный экран»**.

> Благодаря Service Worker (`sw.js`) приложение полноценно функционирует и открывается даже при полном отсутствии подключения к сети.

## 🛠 Локальный запуск и разработка

Приложение не требует компиляции и сборщиков (Vite, Webpack и т.д.):

```bash
# 1. Запуск статического веб-сервера (любой локальный сервер)
python -m http.server 8765 --bind 127.0.0.1

# 2. Откройте в браузере
# http://127.0.0.1:8765

# 3. Запуск тестов (требуется Node.js 22+)
npm test
npm run check
```
