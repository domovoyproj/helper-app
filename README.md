# Helper

Личный помощник для задач, здоровья, рабочих смен и бюджета. Работает в браузере, устанавливается как PWA и хранит основные данные на устройстве.

[Открыть приложение](https://domovoyproj.github.io/helper-app/) · Версия 2.1.0

![Главный экран Helper](docs/screenshots/today-desktop.png)

Главный экран локально запущенного Helper с новым, пустым хранилищем.

## Что можно делать

- Планировать задачи и рабочие смены, рассчитывать зарплату по своим ставкам.
- Вести бюджет, категории операций и взаимные долги.
- Записывать питание, воду, шаги, вес и настроение; смотреть дневную сводку.
- Рассчитывать КБЖУ по описанию или фотографии блюда через Google Gemini.
- Хранить пароли и секреты TOTP в зашифрованном локальном сейфе.
- Экспортировать отчёты в CSV, переносить зашифрованную резервную копию файлом или через GitHub.
- Загружать публичные файлы в свой репозиторий GitHub и получать ссылку.
- Читать публичную сводку KYD; эта интеграция не меняет долги и платежи.

В интерфейсе есть светлая, тёмная и системная темы, компактный режим и палитра действий (`Ctrl+K`, `Cmd+K` или `/`).

## Установка и запуск

Откройте веб-приложение и выберите установку PWA в настройках Helper или меню браузера. На iOS: «Поделиться» → «На экран Домой». Для офлайн-работы сначала откройте приложение с доступом к сети, чтобы оно сохранило ресурсы.

Для локального запуска нужен Python 3. Сборка и установка пакетов не требуются:

```sh
git clone https://github.com/domovoyproj/helper-app.git
cd helper-app
python -m http.server 8765 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8765`. На первом входе задайте мастер-пароль: он используется для шифрования нового локального хранилища. Для существующего хранилища нужен прежний пароль.

## Данные и внешние сервисы

Основное состояние сохраняется в браузере как зашифрованный контейнер `encMasterData`. Очистка данных сайта удаляет локальную копию, поэтому перед ней экспортируйте резервную копию. Мастер-пароль нужен и для расшифровки перенесённых данных.

Сетевые функции включаются по команде пользователя: Gemini получает описание или фотографию блюда, GitHub — зашифрованный бэкап либо выбранный публичный файл, KYD — запрос публичной сводки. TinyURL сокращает ссылки на файлы; Tikwm используется при загрузке видео.

Токены вводятся в настройках и входят в зашифрованные данные. Репозиторий резервных копий должен быть приватным. Репозиторий файлообменника, наоборот, предназначен для открытых материалов: любой загруженный туда файл доступен другим людям.

## Разработка

Для проверок нужен Node.js 22 или новее:

```sh
npm test
npm run check
```

`index.html` содержит экраны, `app.js` — данные и основные функции, `experience.js` — навигацию, темы и сводки. `kyd-connector.js` читает публичную сводку KYD. `sw.js` и `manifest.json` обеспечивают установку и офлайн-кэш; проверки находятся в `tests/`.
